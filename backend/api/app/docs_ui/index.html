Understand status codes and sensor data +

Read responses confidently

200 / 202
Request succeeded / device registration accepted, waiting for a packet.
401 / 403
Sign in again / check account role and workspace access.
409 / 422
Resolve the record conflict / correct the indicated fields.
503
A required connection is unavailable. Inspect readiness and retry.

Keep live values and history distinct

Current packets refresh every 2 seconds. Completed clean windows save 5-minute averages; fault windows retain 1-minute averages, with immediate state-change events.

The durable current state and unfinished averages survive collector restarts. Missing measurements are null; a genuine zero remains zero. An offline gap creates no invented data.

A fresh faulting chamber is connected and needs attention. Inspect packet timestamps and sensor status, not just a green broker connection.
